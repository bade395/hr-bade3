# hr bade3

موقع عربي ثابت لمواصفات وحدة إدارة الموظفين في نظام HR مستقل. يستند التحليل إلى صفحات ZenHR العامة الرسمية ومركز المساعدة، ويميّز بين السلوك الموثق والتصميم المقترح.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى المستودع `hr-bade3`.
2. من إعدادات المستودع افتح **Pages**.
3. اختر النشر من الفرع `main` والمجلد `/ (root)`.
4. سيظهر الموقع على رابط GitHub Pages الخاص بالمستودع.

الصفحة الرئيسية هي `index.html`، وملف المواصفات الكامل متاح للتنزيل من `ZenHR_Reverse_Engineering_Employee_Module.docx`.
